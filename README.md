# 9gn957ptsb-alt.github.io

This repository exists only to keep old links working.

The site used to be served from the `Color-Middling` repository, at
`9gn957ptsb-alt.github.io/Color-Middling/`. That repository was renamed to
**Art-Database**, and GitHub Pages serves a project only under its current
name, so every link built on the old name became a 404 — including the
portfolio link that went to an open call.

GitHub gives this repository (the user site) every path on
`9gn957ptsb-alt.github.io` that no project claims, `/Color-Middling/…`
included. The pages here send each old link on to the same place under
`/Art-Database/`, keeping the rest of the path, the query and the hash:

| Old | Now |
| --- | --- |
| `/Color-Middling/` | `/Art-Database/` — the portfolio |
| `/Color-Middling/?v=2` | `/Art-Database/v2/` — the Artist Website, which opens on the land |
| `/Color-Middling/v2/land.html` | `/Art-Database/v2/land.html` |
| `/` | `/Art-Database/` |

**Do not create a repository named `Color-Middling`.** GitHub redirects git
pushes aimed at the old name to Art-Database only while no repository holds
that name; one that did would also claim `/Color-Middling/` back from this
redirect.

The site itself lives at https://github.com/9gn957ptsb-alt/Art-Database.
